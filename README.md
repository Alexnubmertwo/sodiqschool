# SodiqSchool

Портал школьных инициатив и Telegram-бот подтверждения (`@SodiqLead_bot`).

- `index.html` — фронтенд.
- `sodiqlead-bot/` — сервер (`server.js`) и бот (`bot.js`). Подробности см. в `sodiqlead-bot/README.md`.

Запуск из корня: `npm start` (Node.js 20+). Переменные окружения: см. `sodiqlead-bot/.env.example`.

Файлы `.env` и `data.json` в репозиторий не попадают.
